Interactive Command Manual

Filter, search, and click any command to copy signature or view permissions.

/setup Administrator / Owner

Deploys the persistent visual verification challenge and configures server safeguards.

/setup [log_channel] [verified_role] [staff_role] ...
/trust & /untrust Owner / Creator

Adds or removes a user from the anti-raid trusted list, bypassing safeguard limits.

/trust [user] | /untrust [user]
/antiinvite config Administrator

Enables/disables real-time invite link scanning and configures timeout penalties.

/antiinvite config [enabled] [timeout_minutes]
/antiinvite exempt_channel / role Administrator

Toggles anti-invite exemptions for specific text channels or administrative roles.

/antiinvite exempt_channel [channel]
/kick | /ban | /softban Administrator

Enforces hierarchy-aware kicking, permanent banning, softbanning (clears messages), and unbanning.

/ban [member] [reason]
/timeout | /untimeout | /warn Administrator

Temporarily mutes a user for specified minutes or sends official warning notices via DM.

/timeout [member] [duration_minutes] [reason]
/purge | /lock | /nuke Administrator

Bulk clears messages, locks down channel permissions, or clones & resets channel history (nuke).

/purge [amount] | /nuke
/autosyncall | /synccat Administrator

Bulk syncs channel overrides across all categories or a specific target category.

/autosyncall | /synccat [category]
/quote (or /quo) Everyone

Generates an aesthetic quote image card from a replied message, message ID, or recent chat.

/quote [message_id_or_url]
/welcomer channel / test Administrator

Configures automated welcome cards sent when new members join the server.

/welcomer channel [channel] | /welcomer test

Administrative Setup Guide

Follow these 3 simple steps to configure your server's security grid.

1

Deploy Verification Gateway

Execute /setup in your dedicated verification channel. Select your staff, verified role, log channel, and account age limit. The bot will automatically restrict channel visibility for unverified users and send the interactive captcha portal.

2

Configure Anti-Invite Safeguards

Run /antiinvite config enabled:True to protect chat against unauthorized self-promotions. Exclude media or partner channels using /antiinvite exempt_channel.

3

Lock Conversational AI Channel

Bind AI chat responses to a designated channel by typing #aichannel #ai-chat. This ensures general conversation channels remain clean and unspammed.
